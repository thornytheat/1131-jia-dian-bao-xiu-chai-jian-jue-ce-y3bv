# 保修拆检和换件结算

售后值班人员用收件日和当班时点筛取有效保修单。保修月龄包含末月，安全信号直接送人工。产品序列号是重复受理的组合依据，使用最早有效工单。机型别名按开始日含、结束日不含的活动目录追踪，不允许有效区间相互重叠。

金额全部以整数分记录。历史中已闭单、价格授权文件已公布且已确认的记录可作为训练或时间留出集。训练使用月龄、对数维修分钟和拆装困难分类。对数成本按截断残差训练，风险模型采用 L2 逻辑回归。留出集报告 Brier 损失和有定义的召回率，使用残差中间位置校准成本。

预期换件浪费最高保修成本乘返修风险减拆检费，根据阈值安排拆检。分布外工况保持隔离。整组配件审批同时占用当班和单品库存，不能一单拆成部分批准。结算金额要等于工时、零件费用和税费；结算累计用件不得超过关联授权。

## 风险校准和库存实盘

较早的完工试算窗用于拟合单调失败概率，较晚才受理的维修用于独立评估校准损失。两段之间尚未闭单的行保留为隔离证据，风险模型在校准有收益且失败和成功例子均充足时采用校准结果。拆检阈值对照报告按漏检工单实际历史成本和拆检费列明差异。

可授权库存来自当班期初余额和已经发布且生效的实物流。隔离、解除隔离、到货和旧授权各记一类，未到仓的新件列为后续事件。详单按服务商和保修单挂账，复核通过的各费用项守恒，待查金额不进入核准支出。
